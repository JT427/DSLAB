# DSLAB

Data-structure lab experiments in C++ (arrays, searching, linked lists, stacks, queues, sorting, BST, heap, BFS/DFS).

## 🎬 Reel Maker Studio

[`reel-studio/`](reel-studio/) is a full reel-making web app whose backend is built on these experiments:
the timeline is the doubly linked list (Exp 4), undo/redo uses stacks (Exp 5), the AI job queue is the linked-list
queue (Exp 7), library sorting uses Exp 8/9/10/12, hashtag search is the BST (Exp 11), and Auto Reel uses BFS/DFS (Exp 13).

```
cd reel-studio && npm start   # http://127.0.0.1:5173
```

See [reel-studio/README.md](reel-studio/README.md).
